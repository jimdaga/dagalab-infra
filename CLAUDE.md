# CLAUDE.md

GitOps repo for a 3-node homelab RKE2 cluster on Ubuntu 26.04 bare metal (dagakube01–03.lab.internal = 192.168.3.11–13; public apps on dagaflix.com (Jellyfin), jimdaga.dev reserved for lab experiments; lab VLAN 192.168.3.0/24). Argo CD app-of-apps; see README.md for layout, network plan and bootstrap.

## Conventions

- One folder per app under `argocd/apps/{app}/` containing `application.yaml` (+ `values.yaml` for upstream charts). The root app (`argocd/bootstrap/root-app.yaml`) picks up every `*/application.yaml`. Nothing else to register.
- Upstream charts: multi-source Application, values via `$values/argocd/apps/{app}/values.yaml`. Pin `targetRevision` to an exact version (Renovate bumps it).
- Glue config (CRs that depend on another app's CRDs) goes in a local chart under `helm/charts/{app}` with its own Application.
- Order apps with `argocd.argoproj.io/sync-wave`: CRD/operator apps first, their config after, routes last.
- Keep all Applications on `project: default`, `automated` with `prune` + `selfHeal`, `CreateNamespace=true`, the standard retry block. Add `ServerSideApply=true` for charts with large CRDs.
- No rendering step. Files are applied as written.
- Park an app by renaming its `application.yaml` to `application.yaml.disabled` (root only includes `*/application.yaml`). ExternalSecrets in `helm/charts/secret-stores` take `enabled: false`. Currently parked: external-dns (meant for `jimdaga.dev`). `dagaflix.com` is registered at IONOS with DNS on Cloudflare; the Cloudflare API token is in Vault `secret/cloudflare` (`api-token`), scoped to that zone. The Cloudflare/nameserver move for `jimdaga.dev` (DNS still at IONOS) is deliberately deferred until after the NFL season; don't propose it before then. The user's pick'em app is `family-pickem.com` (already on Cloudflare, proxied), served from the old single-node kubeadm box, not this cluster. Media stack plan and deploy order: README "Media stack plan". Jellyfin is public at `https://popcorn.dagaflix.com` (shared-gateway; unadvertised subdomain behind wildcard DNS + wildcard cert; every other hostname, the bare domain and the raw IP return a blank placeholder page, by design, so the server isn't identifiable), LAN at `jellyfin.lab.internal`. Jellyfin serves from `/` (no BaseUrl): a `/4orr` path was tried and broke TV apps that ignore server paths.
- Secrets live in Vault and reach workloads via ExternalSecrets in `helm/charts/secret-stores`. The only hand-made secret is `vault/vault-aws-kms`. Anything consuming a Vault-sourced secret must sync at a later wave than `secret-stores`.
- Never commit secrets, Vault init output, RKE2 tokens, or kubeconfigs.
- Hosts: bastion (Raspberry Pi) `jim@192.168.3.100`, tooling via `bastion/setup.sh`, sudo needs a password. Nodes `jim@192.168.3.11–13`, passwordless sudo. Identity/static IPs via `scripts/host-config.sh`; node prereqs via `cluster/rke2/node-prep.sh`.
- Network (VLAN 3, 192.168.3.0/24): .10 API VIP (reserved), .11–.13 nodes, .20 daga-nas port 1 (DSM/SMB), .21 daga-nas port 2 (**NFS for Kubernetes only**), .100 bastion, .101–.199 DHCP, .200–.229 MetalLB (.200 public shared-gateway: the UCG forwards WAN 443 here, so every route on it is internet-facing; it carries only Jellyfin on `popcorn.dagaflix.com` Seerr on `requests.dagaflix.com` (Jellyfin sign-in only, local Seerr login off) and Audiobookshelf on `books.dagaflix.com` (own accounts), never platform UIs; `cloudflare-ddns` keeps the record at the WAN IP; .201 LAN gateway for `https://<app>.lab.internal`, homelab CA from `helm/charts/lab-ca`; .202 Plex (LoadBalancer, not via Envoy; the UCG forwards WAN TCP 32400 here, the second internet-facing service)). New UIs get a route in `helm/charts/lan-gateway/values.yaml`, a UniFi DNS record, and a tile in `argocd/apps/homepage/values.yaml`.
- Uptime Kuma (`https://uptime.lab.internal`) monitors every HTTP endpoint, alerting Discord #alerts. Monitors are generated by `scripts/uptime-kuma-setup.sh` (idempotent, `--dry-run`): every lan-gateway and shared-gateway route automatically (`monitorPath` / `monitor: false` on the route entry), anything else from `EXTRA` (LAN: hosts, LoadBalancer services, ports) or `PUBLIC_EXTRA` (internet-facing, e.g. Plex's WAN port) in `scripts/uptime-kuma-setup.py`. Public monitors go out through `vpn-proxy` (Gluetun HTTP proxy on its own PIA tunnel in the `uptime-kuma` namespace, NetworkPolicy-limited to Uptime Kuma) so they test the internet path, not the UCG hairpin. Whenever a service with an HTTP endpoint is added, changed or removed, update the route or `EXTRA` and re-run the script. It only touches monitors tagged `gitops`; ones made in the UI are left alone. Login from Vault `secret/uptimekuma` (`user`, `password`; no 2FA on that account).
- Storage: Longhorn (default, 3 replicas) for app data; media apps share one static NFS claim `media/media-data` from `helm/charts/media-storage` (NAS IP/path set only there). No Synology CSI. Keep SQLite app config on Longhorn, not NFS. Media containers run as DSM user `media` (PUID 1029, PGID 100); DSM share permissions are enforced by numeric UID/GID. Media share layout (inside `/data` = `/volume2/video`, root folders lowercase-hyphen): `movies/Title (Year)/` = Radarr root, `tv/Show (Year)/Season NN/` = Sonarr root, `downloads/{movies,tv}` = qBittorrent categories (same share, so imports hardlink). `theme-parks/` (fan videos, by resort/park: `Walt Disney World/<park>/`, `Disneyland Resort/...`, `Documentaries & TV Specials/`, `Vintage Disney/`, `Unsorted/`), `theme-park-audio/` (park music albums, Jellyfin Music library) and `reorg-logs/` (undo logs + plans of past reorgs) stay outside the *arr roots. Audio lives on two more DSM shares (own PVs in `helm/charts/media-storage`): `audiobooks` (`/volume2/audiobooks`: `library/` = Bookshelf root, `audible/` = Libation) and `podcasts` (`/volume2/podcasts`). subPath mounts can't work on these root-squashed shares (kubelet can't look inside) and the NAS refuses subdirectory mounts: isolate apps with separate shares, not subPaths. `personal/`, `iMovie/`, `youtube/` are backed up by Hyper Backup and DSM-denied to `media`: never move, rename or modify them.
- Media support apps: Recyclarr owns Sonarr/Radarr quality profiles + custom formats (`argocd/apps/recyclarr/values.yaml`; don't edit profiles in the UIs or in `arr-wire.py`); Unpackerr, Bazarr (`scripts/bazarr-setup.sh`), Decluttarr; metrics/dashboards/alerts in `helm/charts/media-monitoring`. Discord notifications: Alertmanager config in `argocd/apps/kube-prometheus-stack/values.yaml`, app side via `scripts/notify-setup.sh` (webhooks in Vault `secret/discord`). See README "Media stack plan" item 6.
- Home Assistant (`argocd/apps/home-assistant`, `https://home.lab.internal`): `hostNetwork` pod for LAN discovery; `configuration.yaml` in its values (git); git-managed automations are HA packages in `helm/charts/home-assistant-packages` (raw files, so Helm doesn't render HA's `{{ }}`; reload Automations after a change); UI state on Longhorn. Sonos can't trust the lab CA, so `/local/` on `home` is also served over plain HTTP (lan-gateway `httpPaths`). `scripts/home-assistant-setup.sh` does onboarding, gateway proxy trust (HA keeps `http:` in `.storage` since 2026.10; YAML `http:` is ignored), the long-lived token (Vault `secret/home-assistant` `api-token`, used by Homepage/Homarr/Prometheus), the Jellyfin user `homeassistant` and the lab integrations; re-run after a rebuild.
- Plex (`argocd/apps/plex`, `https://plex.lab.internal`, direct at 192.168.3.202:32400): Movies + TV shared with friends. No Plex Pass, so no hardware transcoding (CPU only, no GPU request; heavy transcodes belong on Jellyfin). Library `media-data` read-only, DB on Longhorn. Claimed once via `kubectl port-forward` (no claim token anywhere); libraries, remote access and sharing are set in the Plex UI (README "Media stack plan" item 7). Keep "Empty trash automatically after every scan" off. Merge Plex image bumps promptly (internet-facing).
- Audiobooks: Audiobookshelf (`argocd/apps/audiobookshelf`, public `https://books.dagaflix.com`, LAN `https://books.lab.internal`): own accounts (root `jim`, password in Vault `secret/audiobookshelf`); mounts only the `audiobooks` share read-only and `podcasts` read-write, never the video share; libraries scan hourly (no inotify on NFS); `scripts/audiobookshelf-setup.sh` must run before its public route exists on a fresh install (an uninitialised server lets anyone create root). Bookshelf (`argocd/apps/bookshelf`, Readarr fork, `softcover` image = Goodreads metadata via hosted api.bookinfo.pro (the hardcover flavour's hosted search is broken upstream), `https://bookshelf.lab.internal`, LAN only, `External` auth like Sonarr): wired by `arr-wire.py`, which also owns its "Audiobook" quality profile and a release profile requiring an audio term in the raw title (Recyclarr doesn't support it; TorrentLeech's audiobooks sit in its Books category as Unknown Text, so the profile allows that and the release profile keeps ebooks out; custom formats can't, they match the parsed title); root folder monitors nothing by default so one request never grabs a whole catalogue; downloads in `media-data` `downloads/audiobooks`, imports copy (cross-share). Its `seed-cleanup` CronJob deletes audiobook torrents + downloaded files at ratio 3 AND 14 days seeded AND imported (qBittorrent's limits are OR-only); movies/TV still seed forever. Libation (`argocd/apps/libation`): nightly CronJob, Audible account signed in once with `LibationCli login-external` on its PVC (README "Media stack plan" 8), Settings.json from git.
- Prowlarr custom indexer definitions (Cardigann YAML) live in `helm/charts/prowlarr-definitions/definitions/`, mounted at `/config/Definitions/Custom`; Prowlarr only reads them at startup, so restart it after a change. wigornot uses one (its Torznab API rejects text queries on `t=tvsearch`).
- Full lab power-down / power-up (UPS work, power cuts): use the `lab-power-cycle` skill (`.claude/skills/lab-power-cycle`); it pauses Argo, scales storage workloads to 0, waits for Longhorn/NFS to release, powers nodes off, and reverses it. NAS goes down last and comes up first.
- Sports games from YouTube (classic NFL games etc., for a future ErsatzTV): use the `sports-game-download` skill; `scripts/sports-dl.py` (yt-dlp on the Mac, over SMB) writes them to the video share's `sports/<League> Classic Games/Season YYYY/` with `.nfo` files. Season = the year the season started.
- UPS: daga-nas is the NUT server; `scripts/nut-setup.sh` (files in `hosts/nut/`, `nas/`) sets up the NUT clients, the nodes' graceful cluster stop after 10 min on battery (`scripts/lab-power.py --local`), dagakube01's auto-start (marker `/var/lib/dagalab/ups-shutdown.json`) and Wake-on-LAN; the NAS wakes the nodes (`nas/ups-wake.py`, DSM Task Scheduler). Never leave a test `upssched` timer running. Metrics/alerts: `nut-exporter`, `helm/charts/ups-monitoring`. README "UPS / power".
- RKE2 v1.36.5 is running on all three nodes. kubectl from the bastion: `~/.kube/config`, context `dagalab`, API `k8s.lab.internal:6443`. Argo CD is bootstrapped (app-of-apps, all active apps Synced/Healthy); Vault is initialized (init output lives outside the repo). Don't change the cluster or AWS unless asked.
