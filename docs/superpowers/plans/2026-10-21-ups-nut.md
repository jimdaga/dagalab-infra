# UPS (NUT) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The lab reacts to power cuts on its own: NUT clients on the 3 nodes, the webserver and the bastion; a graceful cluster stop after 10 minutes on battery; the NAS waking the nodes when power returns and dagakube01 starting the cluster again; UPS metrics, dashboard, alerts, a Homepage tile and Home Assistant sensors.

**Architecture:** daga-nas is the NUT server (UPS `ups` on 192.168.3.20:3493). Hosts run `nut-client` (`upsmon` as a secondary, `upssched` timers on the nodes) configured by `scripts/nut-setup.sh` from files in `hosts/nut/`. The graceful stop/start logic is `scripts/lab-power.py` (moved from the lab-power-cycle skill) with a node-local mode. `nas/ups-wake.py` on the NAS (DSM Task Scheduler) sends Wake-on-LAN. Metrics come from a `nut-exporter` Argo app; dashboard + alert rules from a `ups-monitoring` local chart.

**Tech Stack:** NUT (Ubuntu `nut-client`), systemd, sudoers, netplan, Python 3 stdlib (unittest), Argo CD + app-template 5.2.1, kube-prometheus-stack (PrometheusRule, ServiceMonitor, Grafana sidecar), promtool (in the Prometheus pod), Homepage, Home Assistant config flows.

**Spec:** `docs/superpowers/specs/2026-10-21-ups-nut-design.md`

    """True once every Longhorn volume is detached; False on timeout or if the API can't be reached."""
    end = time.time() + timeout
    while time.time() < end:
        try:
            if all(v[1] == 'detached' for v in volumes()):
                return True
        except SystemExit:
            pass
        time.sleep(every)

#!/usr/bin/env bash
# NUT clients for the UPS on daga-nas (192.168.3.20:3493, UPS "ups"). Idempotent; re-run after editing hosts/nut/.
#   VAULT_TOKEN=<token> scripts/nut-setup.sh [host ...]        default: all five hosts
# Nodes (192.168.3.11-13): graceful cluster stop after 10 min on battery, auto-start, Wake-on-LAN (hosts/nut/).
# Webserver 192.168.4.10 + bastion 192.168.3.100: plain shutdown at low battery. Also copies nas/ups-wake.py to the NAS.
# Login from Vault secret/nut; README "UPS / power".
set -euo pipefail
: "${VAULT_TOKEN:?}"
cd "$(dirname "$0")/.."
v() { kubectl -n vault exec -i vault-0 -- env VAULT_TOKEN="$VAULT_TOKEN" vault "$@"; }
NUT_USER=$(v kv get -field=username secret/nut); NUT_PW=$(v kv get -field=password secret/nut)
NODES="192.168.3.11 192.168.3.12 192.168.3.13"
HOSTS=$(for x in ${*:-$NODES 192.168.4.10 192.168.3.100}; do [ "$x" = 192.168.3.20 ] || printf '%s ' "$x"; done)   # the NAS isn't a NUT client

put() {   # put <host> <dest> <mode> <owner> < content ; prints "changed" if the file changed
  ssh -o BatchMode=yes "jim@$1" "t=\$(mktemp); cat > \$t; if sudo cmp -s \$t $2; then rm \$t; else sudo install -m $3 -o ${4%:*} -g ${4#*:} \$t $2 && rm \$t && echo changed; fi"
}

for h in $HOSTS; do
  echo "== $h"
  ssh -o BatchMode=yes "jim@$h" 'dpkg -l nut-client 2>/dev/null | grep -q ^ii || { sudo DEBIAN_FRONTEND=noninteractive apt-get install -y -qq nut-client >/dev/null && echo "  installed nut-client"; }'
  c=""
  c+=$(put "$h" /etc/nut/nut.conf 640 root:nut < hosts/nut/nut.conf)
  c+=$(sed -e "s/__USER__/$NUT_USER/" -e "s/__PASSWORD__/$NUT_PW/" hosts/nut/upsmon.conf.tmpl | put "$h" /etc/nut/upsmon.conf 640 root:nut)

  c+=$(put "$h" /etc/nut/upssched.conf 640 root:nut < hosts/nut/upssched-plain.conf)   # Task 3: nodes get upssched-node.conf

- [ ] **Step 2: Write `nas/ups-wake.py`**

```python
#!/usr/bin/env python3
"""Wake the k8s nodes after a power outage. Runs on daga-nas (DSM Task Scheduler, user jim); stdlib only.

  ups-wake.py watch [--dry-run] [--status "OL CHRG"] [--state FILE]     every minute
  ups-wake.py boot  [--dry-run]                                          at DSM boot-up

watch: acts only after it has SEEN the UPS on battery (OB). Once mains (OL) has been back for 2 minutes it wakes every
node that doesn't answer (ssh/6443), for up to 30 minutes, then forgets the outage. No outage seen -> never wakes
anything, so a manual maintenance shutdown is left alone.
boot: the NAS itself lost power (the battery ran out). Wait until NFS answers, then wake the nodes. With node BIOS
"restore on AC loss: stay off" this is what starts them, after the NAS is fully up.
"""
import argparse, json, os, socket, sys, time

NODES = {'dagakube01': ('192.168.3.11', 'd8:bb:c1:2d:b1:95'),
         'dagakube02': ('192.168.3.12', '00:d8:61:1d:af:7f'),
         'dagakube03': ('192.168.3.13', '00:d8:61:47:65:37')}
BROADCAST = ('192.168.3.255', 9)
NUT = ('127.0.0.1', 3493)
NFS = ('192.168.3.21', 2049)
STATE = os.path.expanduser('~/dagalab/ups-wake-state.json')
SETTLE, WINDOW = 120, 1800


def log(msg): print(time.strftime('%Y-%m-%d %H:%M:%S'), msg, flush=True)


def ups_status():
    with socket.create_connection(NUT, timeout=5) as s:
        s.sendall(b'GET VAR ups ups.status\n')
        line = s.makefile().readline()          # VAR ups ups.status "OL CHRG"
    if not line.startswith('VAR '):
        raise RuntimeError(line.strip())
    return line.split('"')[1].split()


def step(state, flags, now, is_up):
    """Pure decision. state: {} or {'outage': ts, 'online_since': ts|None}. Returns (new_state, node names to wake)."""
    state = dict(state or {})
    if 'OB' in flags:
        state.setdefault('outage', now)
        state['online_since'] = None
        return state, []
    if 'OL' not in flags or 'outage' not in state:
        return state, []
    if not state.get('online_since'):
        state['online_since'] = now
    since = now - state['online_since']
    if since >= SETTLE + WINDOW:
        return {}, []
    if since < SETTLE:
        return state, []
    return state, [n for n, (ip, _) in NODES.items() if not is_up(ip)]


def is_up(ip):
    for port in (22, 6443):
        try:
            socket.create_connection((ip, port), timeout=1).close()
            return True
        except OSError:
            pass
    return False


def magic(mac):
    return b'\xff' * 6 + bytes.fromhex(mac.replace(':', '')) * 16


def wake(names, dry):
    for n in names:
        mac = NODES[n][1]
        if dry:
            log(f'[dry-run] wake {n} {mac}')
            continue
        with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as s:
            s.setsockopt(socket.SOL_SOCKET, socket.SO_BROADCAST, 1)
            s.sendto(magic(mac), BROADCAST)
        log(f'woke {n} {mac}')


def watch(a):
    try:
        state = json.load(open(a.state))
    except (OSError, ValueError):
        state = {}
    flags = a.status.split() if a.status else ups_status()
    new, names = step(state, flags, time.time(), is_up)
    if new != state:
        log(f'status {" ".join(flags)}: state {new or "cleared"}')
    wake(names, a.dry_run)
    if not a.dry_run:
        os.makedirs(os.path.dirname(a.state), exist_ok=True)
        json.dump(new, open(a.state, 'w'))


def boot(a):
    end = time.time() + 1200
    while time.time() < end:
        try:
            socket.create_connection(NFS, timeout=3).close()
            break
        except OSError:
            time.sleep(10)
    else:
        log('NFS not up after 20 min: waking the nodes anyway')
    wake([n for n, (ip, _) in NODES.items() if not is_up(ip)], a.dry_run)
    if not a.dry_run and os.path.exists(a.state):
        os.remove(a.state)


if __name__ == '__main__':
    p = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    p.add_argument('mode', choices=['watch', 'boot'])
    p.add_argument('--dry-run', action='store_true')
    p.add_argument('--status', help='simulate ups.status flags, e.g. "OB DISCHRG"')
    p.add_argument('--state', default=STATE)
    a = p.parse_args()
    {'watch': watch, 'boot': boot}[a.mode](a)
```
