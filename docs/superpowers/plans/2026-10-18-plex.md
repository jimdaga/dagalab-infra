# Plex Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run Plex Media Server on the cluster with the Movies + TV library, reachable on the LAN and directly from the internet for friends.

**Architecture:** An Argo CD app `plex` (bjw-s app-template 5.2.1) in namespace `media`, CPU-only, config on Longhorn, library read-only from the `media-data` NFS claim. A dedicated MetalLB LoadBalancer IP 192.168.3.202:32400 (`externalTrafficPolicy: Local`) that the UCG port-forwards from WAN 32400; LAN UI via the existing LAN gateway at `https://plex.lab.internal`.

**Tech Stack:** Argo CD (app-of-apps, multi-source), bjw-s app-template 5.2.1, `plexinc/pms-docker`, MetalLB 0.16.1 (L2), Envoy Gateway (lan-gateway chart), Homepage.

**Spec:** `docs/superpowers/specs/2026-10-18-plex-design.md`

## Global Constraints

- Commits go straight to `main` and are pushed (Argo CD syncs `main`). Trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never commit secrets, claim tokens, Plex tokens, Vault output or kubeconfigs.
- Image `plexinc/pms-docker:1.43.4.10903-e5521bd8c` (exact tag, never `latest`).
- Runs as DSM user `media`: `PLEX_UID=1029`, `PLEX_GID=100`.
- `ADVERTISE_IP=http://192.168.3.202:32400/`, `ALLOWED_NETWORKS=192.168.0.0/16`, `TZ=America/New_York`.
- Strategy `Recreate`; CPU only (no `gpu.intel.com/i915`); requests `500m`/`1Gi`, memory limit `4Gi`.
- Storage: `/config` Longhorn PVC 30Gi RWO; `/transcode` emptyDir `sizeLimit: 20Gi`; `/data` = claim `media-data`, read-only.
- Service: LoadBalancer, annotation `metallb.io/loadBalancerIPs: 192.168.3.202`, TCP 32400, `externalTrafficPolicy: Local`.
- `.200` (public shared-gateway) is untouched; Plex is not routed through Envoy for WAN traffic.
- kubectl context `dagalab`. Don't touch Jellyfin. Personal NAS folders `personal/`, `iMovie/`, `youtube/` are never libraries.
- No `python3 -m py_compile` (it rewrites tracked `scripts/__pycache__`). In zsh never name a variable `path`.

## Review Focus

1. Clients on the main LAN being treated as remote (bandwidth-limited/relayed) because `externalTrafficPolicy` isn't `Local` or `ALLOWED_NETWORKS` is missing. Task 1 Step 6 asserts both; Task 4 Step 3 checks the client shows as local.
2. Plex unable to read the library because it runs as root on a root-squashed NFS share. Task 1 Step 7 reads `/data/movies` as the Plex user.
3. Plex writing into the library (e.g. if `/data` were mounted RW). Task 1 Step 7 asserts a write fails.
4. A second Plex pod starting on the same Longhorn volume during a rollout. Task 1 Step 2 asserts `Recreate`.
5. The LAN route accidentally landing on the public `.200` gateway. Task 2 Step 2 asserts the `plex-lan` HTTPRoute's parent is `lan`.

- [ ] **Step 4: Write `argocd/apps/plex/values.yaml`**

```yaml
# Plex Media Server: Movies + TV shared with friends (they have Plex Pass; this server doesn't, so no hardware
# transcoding, LAN included: CPU only, and the GPU share stays with Jellyfin). LAN UI: https://plex.lab.internal.
# Direct remote access: dedicated MetalLB IP 192.168.3.202:32400, which the UCG forwards from WAN TCP 32400 (the
# second internet-facing service; it bypasses Envoy and the .200 gateway). Library is the shared NFS claim,
# READ-ONLY; Plex's DB/metadata on Longhorn. One-time claim/libraries/sharing: README "Plex".
controllers:
  plex:
    strategy: Recreate   # never two Plex instances on one database
    containers:
      app:
        image:
          repository: plexinc/pms-docker
          tag: 1.43.4.10903-e5521bd8c
        env:
          TZ: America/New_York
          # the image's init starts as root, then runs Plex as DSM user `media` (root is squashed on the NFS share)
          PLEX_UID: "1029"
          PLEX_GID: "100"
          ADVERTISE_IP: http://192.168.3.202:32400/
          # main LAN + VLAN 3 count as local: no bandwidth limits, no relay
          ALLOWED_NETWORKS: 192.168.0.0/16
        probes:
          liveness: &probe
            enabled: true
            custom: true
            spec:
              httpGet:
                path: /identity
                port: 32400
              periodSeconds: 30
              failureThreshold: 5
          readiness: *probe
          startup:
            enabled: true
            custom: true
            spec:
              httpGet:
                path: /identity
                port: 32400
              periodSeconds: 10
              failureThreshold: 30   # first start initialises the database
        resources:
          requests:
            cpu: 500m
            memory: 1Gi
          limits:
            memory: 4Gi

service:
  app:
    controller: plex
    type: LoadBalancer
    annotations:
      metallb.io/loadBalancerIPs: 192.168.3.202
    externalTrafficPolicy: Local   # real client IPs, so Plex can tell LAN from remote
    ports:
      http:
        port: 32400

persistence:
  # Plex DB + metadata: Longhorn, never NFS
  config:
    type: persistentVolumeClaim
    accessMode: ReadWriteOnce
    size: 30Gi
    globalMounts:
      - path: /config
  # transcodes: node-local scratch
  transcode:
    type: emptyDir
    sizeLimit: 20Gi
    globalMounts:
      - path: /transcode
  # libraries: Movies /data/movies, TV /data/tv
  data:
    type: persistentVolumeClaim
    existingClaim: media-data
    globalMounts:
      - path: /data
        readOnly: true
```
